# 桌面宠物 - 使用说明

用你提供的旗袍小人图片做成的桌面宠物程序，基于 PyQt5 实现。

## 目录结构

```
petproject/
├── main.py              # 程序入口，运行这个文件即可
├── desktop_pet.py        # 桌面宠物核心逻辑
├── requirements.txt       # 依赖库
├── assets/
│   ├── character.png     # 已抠图（透明背景）的角色图片
│   └── original.jpg      # 你上传的原图（备份，程序不使用）
└── README.md
```

## 在 PyCharm 中运行

1. 用 PyCharm 打开 `petproject` 这个文件夹（File → Open）。
2. 打开右下角的 Python 解释器设置，确认使用的是你电脑上的 Python（建议 3.8 及以上）。
3. 打开 PyCharm 自带的 Terminal，安装依赖：
   ```
   pip install -r requirements.txt
   ```
4. 打开 `main.py`，点击右上角绿色三角形（Run）运行。
5. 运行后，小人会出现在屏幕右下角，程序没有任何窗口边框，也不会出现在任务栏（只在系统托盘里有一个小图标）。

## 功能 / 动作说明

由于你只提供了一张静态图片，所有"动作"都是通过程序动画（位移、缩放、翻转、抛物线跳跃等）模拟出来的，具体包括：

| 动作 | 触发方式 | 效果 |
|---|---|---|
| 待机呼吸 | 自动，无操作时 | 小人原地轻微上下浮动，像在呼吸 |
| 随机走动 | 自动，每隔几秒随机触发 | 小人在屏幕底部左右走动，走到屏幕边缘会自动转身（图片水平翻转） |
| 跳一跳 | 双击小人 / 右键菜单"跳一跳" | 小人沿抛物线跳起再落下 |
| 说话 | 单击小人（点击但不拖动）/ 右键菜单"说句话" | 头顶弹出气泡，显示随机的可爱台词 |
| 自由拖拽 | 按住鼠标左键拖动 | 小人跟随鼠标到屏幕任意位置，松手后继续待机 |
| 隐藏/显示 | 右键菜单 或 单击系统托盘图标 | 隐藏/重新显示小人 |
| 退出 | 右键菜单"退出" 或 托盘菜单"退出" | 关闭程序 |

## 想调整的地方

打开 `desktop_pet.py`，文件开头有几个常量可以直接改：

```python
PET_HEIGHT = 220   # 小人显示的高度（像素），改大改小都可以
WALK_SPEED = 2     # 走路速度
FRAME_MS = 30      # 动画刷新间隔，数值越小越流畅（也越吃CPU）
PHRASES = [...]    # 说话台词，可以自己增删
```

## 想要更丰富的动作？

如果之后你能提供多张不同姿势的图（比如挥手、走路的两个脚步姿势、坐下等），
把这些图放进 `assets` 文件夹，告诉我文件名，我可以帮你改成"多帧切换"的真实动画，
而不是现在这种用一张图做位移/翻转模拟出来的效果，会更生动。
